RPG Companion
Toggle to enable/disable the RPG Companion extension. Configure additional settings within the panel itself.
GM Mode GM Mode uses a separate API to generate world narration, location tracking, and game mechanics. Configure API connections in the in-panel Settings popup.
Rolling Summary
Injects a rolling story summary at a deep prompt position for Bedrock prefix caching stability. Recent beats are injected at a shallower depth.
Co-Op Relay
Formats GM narration for clipboard relay to a partner SillyTavern instance running your character AI.
Memory Recollection
Summarizes chat history into lorebook entries for automatic recall via keyword triggers.
Lorebook Limiter
Caps the number of World Info entries activated per generation to prevent token bloat.
Agent Pipeline
Orchestrates pre-generation, parallel, and post-processing agents. Required for Narrative Director, World State, and Scene Model.
Narrative Director
Pre-generation agent that creates story direction hooks. Use the "Push Story" button in the GM panel to trigger a narrative push.
World State Tracker Post-processing agent that auto-tracks date, time, location, weather, temperature, and characters from the conversation.
NPC System
Tracks NPC profiles with reputation (-100 to +100). Relevant NPCs are injected into the prompt based on recent mentions.
NPC Dialogue Router
API Connection
Routes NPCs with a personality field to a separate LLM for independent dialogue generation. Reputation changes are applied N-1 (next turn) for swipe safety. Uncheck "Use GM API" to set a dedicated endpoint for NPC dialogue.
Session Management
Multi-session campaigns with summary carry-forward. Past session recaps are injected as campaign history.
Campaign Planning Manage story arcs with plot points and pre-planned encounters. Active arc and pending encounters are injected into the GM prompt.
Maps
Overworld grid or dungeon node-graph with discovery tracking and fog of war. Map data is injected into the GM prompt.
Scene Model Parallel agent that generates scene descriptions during main generation. Runs via separate API connection.

Recommended Models:
For the extension to work properly, it is not recommended to use any models below 20B, especially if they're old. It works best with the SOTA models such as Deepseek, Claude, GPT, or Gemini.
